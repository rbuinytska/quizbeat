# 🎵 QuizBeat — Мобильный Веб-Тренажер для Музыкальных Квизов

Интерактивное мобильное веб-приложение (PWA) для тренировки и подготовки команды к музыкальным квизам («Party's Quiz», «Угадай мелодию», ретро-квизы и вечеринки).

Работает как **нативное мобильное приложение** на iPhone и Android при добавлении на экран «Домой», а также в любом браузере.

---

## ⚡ Ключевые возможности

1. **Два источника музыки**:
   * 🎧 **Spotify Premium (Web Playback SDK + API)**:
     * Прямая авторизация через официальный OAuth 2.0 PKCE (работает без бэкенда на GitHub Pages).
     * Полноценное воспроизведение треков в браузере.
     * Загрузка любых Spotify-плейлистов (по ссылке или из вашей медиатеки).
   * 📻 **Instant / Offline Demo режим (iTunes Audio Engine)**:
     * Встроенные готовые квиз-паки: *«Легенды 90-х»*, *«Золотые 2000-е»*, *«Рок & Глэм Хиты»*, *«Диско 80-х»*.
     * Онлайн-поиск любых исполнителей (Руки Вверх, Queen, хиты 2000-х и т.д.) с автоматической нарезкой 30-секундных превью без необходимости входить в аккаунты.

2. **3 режима тренировки**:
   * 🎯 **4 Варианта (Классика квиза)**: играет отрывок (5с, 10с, 15с), 4 кнопки ответа, комбо-стрики и конфетти.
   * 🚨 **Фальстарт / Своя игра (Buzzer Party Mode)**: большая светящаяся кнопка для игры с друзьями вслух. Кто первый нажал — музыка встает на паузу, есть 5 секунд на ответ!
   * 🃏 **Флэш-карточки (Интервальное запоминание)**: 3D переворот карточки («Слушаю» $\rightarrow$ «Проверяю» $\rightarrow$ «Помню / Забыл»).

3. **Работа над ошибками (Weak Tracks)**:
   * Все треки, в которых вы ошиблись, сохраняются в отдельный список.
   * Можно запустить режим тренировки **только по забытым трекам**, пока вы не выучите их назубок.

4. **Мобильный UX (PWA)**:
   * Стилизация под мобильное приложение, поддержка жестовых зон и вырезов iPhone (Safe Area).
   * Web Audio синтезатор для звуковых эффектов (мгновенный отклик без лагов).
   * Виниловая анимация и эквалайзер.

## 🚀 Как запустить локально

```bash
cd scratch/music-quiz-app
npm install
npm run dev
```
Откройте в браузере: `http://localhost:5173/`


### 2. Бесплатный хостинг (на выбор):

* **Вариант A: GitHub Pages (бесплатно)**:
  1. В вашем репозитории на GitHub перейдите в **Settings** $\rightarrow$ **Pages**.
  2. В поле *Build and deployment* выберите **GitHub Actions**.
  3. Готово! Сайт будет доступен по адресу `https://<ваш-юзернейм>.github.io/<имя-репозитория>/`.

* **Вариант B: Vercel / Netlify (в 1 клик)**:
  1. Зайдите на [vercel.com](https://vercel.com) $\rightarrow$ *Add New Project*.
  2. Выберите ваш GitHub-репозиторий и нажмите *Deploy*.

## 📱 Как установить на телефон как приложение (PWA)

1. Откройте ссылку на сайт в мобильном браузере:
   * **iOS (iPhone Safari)**: Нажмите иконку **«Поделиться»** (квадрат со стрелкой вверх) $\rightarrow$ выберите **«На экран Домой»** (Add to Home Screen).
   * **Android (Chrome)**: Нажмите меню с тремя точками $\rightarrow$ **«Установить приложение»**.
2. Иконка **QuizBeat** появится на рабочем столе телефона. Приложение открывается на весь экран, без адресной строки и кнопок браузера!

## 🎧 Настройка Spotify Premium (2 минуты)

1. Зайдите в [Spotify Developer Dashboard](https://developer.spotify.com/dashboard).
2. Нажмите **Create App**.
3. Укажите:
   * **App name**: `QuizBeat`
   * **Redirect URIs**: адрес вашего приложения (например, `http://localhost:5173/` для локального запуска или `https://ваш-юзернейм.github.io/music-quiz-app/`).
   * **Which API/SDKs are you planning to use?**: выберите `Web Playback SDK` и `Web API`.
4. Скопируйте **Client ID** и вставьте его в настройки внутри приложения (вкладка *Настройки* $\rightarrow$ *Войти через Spotify*).
